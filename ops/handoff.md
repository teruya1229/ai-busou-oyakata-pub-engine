# handoff

## 次にやるべき1手
- 実例入力を複数回流し、4コマ→note→Xで語り口と学びが一貫するよう微調整する。

## 判断基準
- 1入力で3出力が破綻なく出ること
- トーン選択が文体に反映されること
- 読んだときに「最後の小さな学び」が明確であること
- テーマ未入力や短文入力でも不自然な空欄が出ないこと

## 今回やらないこと
- 永続化（保存/履歴）
- 外部AI API接続
- Kindle用出力
- 複数画面化や高度なUI演出

## 実装方針
- ルールベースを維持し、`engine.js` の関数を拡張していく
- 変更多発を避けるため、`templates.js` 側で文言差分を吸収する
- `app.js` はUIイベントと表示に限定する

## 注意点
- 静的構成を維持し、buildツールを導入しない
- UTF-8前提で文字化けを避ける
- 1画面完結UIのまま、過剰機能を入れない
- `templates.js` と `engine.js` を中心に最小差分で改善する

## 次の拡張候補
- 現場ジャンル別テンプレ（内装/設備/外構など）
- 文字数制約を考慮したX投稿最適化
- 出力プリセット（朝礼向け/振り返り向け）
- 将来のAPI差し替えポイントのインターフェース化
